# GP 리서치 로그 (2라운드)
- 유효 검색어: "knee slice pass opponent blocks underhook switch to leg drag", "leg drag pass opponent turns ... take the back", "torreando ... folding pass".
- page-read 성공: Digitsu 영상 설명(Herle, Grippo, Najmi, Marcus Johnson, Frazatto) 및 Digitsu 패스 페이지(Leg Drag, Knee Cut), Jitsu IQ 레그 드래그.
- 한계: Digitsu 영상은 유료라 텍스트 설명만 확인(영상 미시청). Evolve 토레안도 글, Schreiner 더블언더 영상은 검색 요약만 확인(snippet). 더블 언더 -> 롱스텝, 엑스패스, 카트휠, 오버/언더 체인은 근거 부족으로 제외.
- 접근 문제: 차단 도메인 없음.
- DB 부족: 스매시/트럭 후 백 진입 전용 기술, 백스텝 패스, 레그 위브 패스.
- 노기/기: 스택/롱스텝 칼라 그립, 니 슬라이스 Herle 설명은 도복 그립 전제. 레그 드래그와 폴딩은 노기 가능.
