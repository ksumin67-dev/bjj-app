# LS (라소 가드) 2라운드 로그 (2026-10-10)

결과: 5개 (검증됨 1, 참고 3, 초안 1). 본문 열람(page-read) 출처: Digitsu 기술 사전(lasso-sweep, lasso-guard, lasso-back-take), Digitsu Stolfi 영상 설명(gu-triangle-omoplata, transitions), Digitsu "All About the Lasso Guard", Evolve MMA 라소 스윕 글(grep으로 해당 구간만), Grapplearts 라소 스파이더 오모플라타, Jitsu IQ 라소 가드.

## 유효했던 검색어
- "lasso guard triangle armbar omoplata options opponent reacts" (Stolfi/Digitsu 페이지 발견)
- "lasso guard to DLR or single leg x when opponent stands" 
- 영어 + 구체 기술명 조합이 유효. 한국어 검색은 시도하지 않음(프로토콜).

## 출처 신뢰도 메모
- Digitsu /t/ 기술 사전 페이지는 구조화된 요약형이며 강사 개인 서술이 아님 -> 독립 출처 판단 시 보수적으로 취급.
- Digitsu /v/ 영상 페이지는 강사(Stolfi 등) 영상의 텍스트 요약이며 영상은 유료라 열람 불가.
- Evolve MMA 글은 체육관 블로그. Jitsu IQ는 위키형 요약.
- Grapplearts(Kesting)는 신뢰도 높으나 본문이 짧고 트리거 설명이 적음.

## 접근 문제
- 차단된 도메인 없음. 일부 페이지(Evolve)는 67k자로 파일 저장되어 grep으로 필요 구간만 열람.
- Digitsu 영상 본편, Grapplearts 일부 하위 링크(elbow pull omoplata 영상)는 열람 불가.
