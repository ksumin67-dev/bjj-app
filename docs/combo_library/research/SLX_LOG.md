# SLX 리서치 로그 (2라운드, 2026-10-10)

- 결과: 4개 콤보 (검증됨 0 / 참고 3 / 초안 1). 목표 5~8개에는 미달 — 근거가 있는 연계가 적었음.
- 유효한 검색어: "single leg x guard sweep fails opponent stays standing ankle lock", "single leg x guard kneebar when opponent straightens leg or hops", "IBJJF leg lock rules by belt".
- 본문 열람 성공: evolve-mma.com SLX 3공격(저장 파일을 grep/Read로 확인), digitsu.com SLX/SLX 스윕, jitsuiq.com SLX, bjjee.com 빅터 우고 니바 글.
- 접근 문제: 없음. 아웃사이드 아시 진입 전용 강의(Damien, Eddie Cummings 등)는 유료라 열람 불가.
- 한계: SLX 포지션은 위키형 요약(jitsuiq, digitsu)이 많아 '조건→다음 기술' 형태의 트리거를 담은 출처가 드묾. 검증됨 후보는 2차 라운드에서 Lachlan Giles/Grapplearts SLX 마스터클래스 등 강사 본인 자료로 재시도.
- 도감 누락 제안: SLX → X가드 전환(SLX to X-Guard), SLX 웨이터 스윕, 스탠드업 스윕 변형(오버훅 SLX), 아킬레스/앵클락 변형(배로 엎드린 앵클락), 힐훅 이전 단계의 '힐 슬립'류.
- 룰 메모: 스트레이트 앵클락은 IBJJF 전 벨트 허용, 니 리핑(리프)은 IBJJF 금지, 토홀드/니바는 상위 벨트 위주, 힐훅은 기 대회 전반 금지(노기 상위 부문 제외, 출처 간 상이). 앱 노출 시 룰 경고 필요.
