# BC (백 컨트롤) 리서치 로그

## 결과 요약
- 8개 콤보: 검증됨 2, 참고 3, 초안 3 (BC-05 시스템 콤보, 암바 실패 후 마운트, RNC 막히면 보우 앤 애로우)

## 검색 방식
- WebSearch 10회(영어 8, 한국어 2), 페이지 본문 fetch는 하지 않음. 모든 근거는 검색 결과 요약(스니펫)에 근거한 것이며 본문 정독으로 재확인 필요.
- 유효: "<기술A> defended <기술B> from back" 형태의 영어 질의, graciebarra.com / bjjee.com / evolve 계열 블로그 / digitsu / grapplearts / jitsuiq 도메인이 반복 노출.
- 효과 없음: 한국어 질의는 영어 결과만 반환. 한국어 출처 0건. Jiu-Jitsu Times 문서는 한 건도 안 나옴. "Systematic back attack" 같은 BC-05 명칭 검색은 해당 명칭의 출처 없음.
- 접근 차단 없음(차단된 도메인 없음). 일부 결과는 무관/스팸 도메인이라 제외함.

## 출처 신뢰도 메모
- 강사 본인 채널/교본 직접 근거는 거의 확보 못 함. Gracie Barra 클래스가 가장 근거 수준이 높음.
- evolve 계열 블로그, digitsu 요약, jitsuiq는 2차 교육 사이트(프로토콜 2순위). 포럼(bullshido)은 보조 취급만.
- 검증됨 2건도 둘 다 스니펫 확인 수준이라 사람 검수 시 우선 확인 권장.

## 열린 질문
- BC-05 "백 시스템 초크 콤보"가 정확히 무슨 기술인지(도감 설명) 확인 필요.
- 트라이앵글 from back, 손목락, 칼라 초크 변형(로저 그레이시 기무라 → 깃 초크)은 도감에 BC 코드가 없어 미반영. 다른 코드에 있는지 확인.
- 스트레이트 자켓 → 보우 앤 애로우는 1곳만 근거. Danaher/Marcelo/Roger 등 강사 직접 자료 추가 탐색 필요.
- 암바 이후 마운트 전환(BC-10) 연계는 근거 없음.

## 라운드 3 (2026-10-10)
- 신규: bc-kimura-triangle(검증됨: Evolve University + Grapplearts(이전 라운드 본문 확인 재사용) + Digitsu 백 트라이앵글), bc-backtriangle-armbar(검증됨: Digitsu + Evolve MMA + Grapplearts; 트리거는 서술 안 됨), bc-rnc-backtriangle(참고: RNC 방어 -> 백 트라이앵글은 Evolve MMA 1곳).
- 재시도: bc-rnc-bowarrow-gi 초안 -> 참고(Digitsu Barlaan: RNC보다 보우 앤 애로우 선호). bc-system-choke-short, bc-armbar-mount-exit는 초안 유지.
- 유효했던 검색어: "back triangle from back control when rear naked choke defended opponent arms", "back control bow and arrow choke when rear naked choke blocked".
- 한계: Grapplearts 삼각 가이드는 이번 세션에서 재열람 불가(중복 요청 차단)라 이전 라운드 본문 확인 기록을 신뢰함.
