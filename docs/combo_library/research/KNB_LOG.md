# KNB 리서치 로그 (2라운드, 2026-10-10)

결과: 5개 (검증됨 2 / 참고 3 / 초안 0). page-read 출처: Gracie Barra(Feitosa KOB 시퀀스), Evolve University(KOB 5공격), Jitsu IQ KOB, Digitsu KOB, Grapplearts(KOB 초크), Evolve 베이스볼 초크(grep으로 해당 구간).

유효했던 검색어/출처
- "knee on belly cross choke armbar opponent pushes knee transition" -> GB, Evolve, Digitsu 등 반응 기반(무릎 밀기 -> 암바) 설명이 잘 나옴.
- Gracie Barra 글은 짧고 반응별 분기(무릎 밀기/벨트 잡기/가슴 밀기)가 명확해 가장 가치 있는 출처.

실패/한계
- 베이스볼 초크 실패 시 백 테이크 연결, 크로스 초크를 방어당했을 때의 갈래는 직접 다룬 출처 없음.
- Evolve가 소개한 아메리카나/다르스(KOB)는 DB에 없음 -> 추가 제안: 아메리카나 (니 온 벨리), 다르스 초크 (니 온 벨리), 니 온 벨리 니 슬라이드 아웃 후 백스텝 등.
- Feitosa의 180도 암바가 DB의 스피닝 암바(KNB-05)인지 일반 암바(KNB-01)인지 불확실.
- Jitsu IQ와 Digitsu의 포지션 페이지는 일반론이라 독립 연계 근거로는 약함.

열린 질문
- KNB-05 스피닝 암바와 연결되는 상대 반응(예: 상대가 몸을 돌려 엎드릴 때)의 직접 출처.
- 기/노기 구분(칼라 그립 의존: KNB-03, KNB-04).
