## 유효했던 검색
- "<기술A> <기술B> combination closed guard" 형태 영어 쿼리: BJJEE, Evolve, Grapplearts, jiujitsu.com, Digitsu 등이 나옴.
- "closed guard armbar triangle omoplata combination when they pull arm out": 반응(트리거) 기반 설명이 가장 잘 나옴.
- 반응 문구(when they post / defend)를 넣으면 if_blocked 트리거 근거를 얻기 쉬움.

- 한국어 쿼리: 한국어 근거 출처 없음(영문 자료 요약만 반환). 나무위키는 위키성이라 근거로 불인정.
- "Jiu-Jitsu Times" 특정 검색: 해당 사이트 결과 없음.
- 암드래그 백테이크(CG): Marcelo Garcia 사례는 버터플라이/스탠딩 위주, 클로즈드 가드 구체 근거 못 찾음.
- 힙범프 -> 길로틴 직접 연계: 약한 근거만(상대가 앞으로 밀 때 목 노출).
