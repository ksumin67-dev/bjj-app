# ZG (Z가드/니실드) 2라운드 로그 (2026-10-10)

콤보 미작성. DB에 ZG(포지션 자체)와 ZG-20(Z가드 베이팅 컨트롤) 두 개뿐이라 2단계 이상 연계를 만들 수 있는 기술 ID가 없음.
참고용으로 확인한 사실(검색 요약만, 본문 미열람): 니실드에서 상대가 압박하면 니 레버 스윕, 플래튼하며 밀면 언더훅 백 테이크가 흔한 흐름.
DB 보강 제안: 니 레버 스윕(Knee Lever Sweep), 니실드 백 테이크(Knee Shield Back Take), 니실드 암 드래그, 니실드 → 하프가드 언더훅 스윕, 니실드 → 라소/Z가드 전환 스윕.
