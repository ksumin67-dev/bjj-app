# SC 리서치 로그 (2026-10-10, 라운드 1)

## 결과 요약
- 8개 콤보: 검증됨 2 / 참고 5 / 초안 1

## 유효했던 검색어 / 출처
- 영문 "side control kimura armbar chain when opponent pulls arm in" -> Digitsu(Barlaan), Awesome Jiu Jitsu(Lachlan Giles 정리), Grapplearts. 가장 수확이 컸음.
- 영문 "side control to back take ... rear naked choke" -> Graciemag(Gordinho), Digitsu.
- 출처 유형: 블랙벨트 강사 기술 글(Grapplearts, Graciemag), 강사 영상 정리 블로그, Digitsu 코스 설명.
- 직접 열람(web_fetch) 성공: Awesome Jiu Jitsu, Grapplearts(two-powerful-armbars), Graciemag, Jitsu IQ arm-triangle.

## 약했던 검색어 / 실패
- 한국어 검색("사이드 컨트롤 기무라 암바 연결", "마운트 전환 암바 강의")은 영어 결과만 나옴. 한국어 강사/채널 출처 0건.
- 다르세 -> 아나콘다 연계는 검색 결과가 없음(아나콘다는 프런트 헤드락 설명 위주). 포럼(martialtalk)은 근거로 불인정.
- Evolve MMA "Top 7" 페이지는 크기 초과로 본문 열람 실패(검색 요약만 참고, 근거로 쓰지 않음).

## 접근 문제
- 차단된 도메인은 없었음. 일부 페이지는 크기 제한으로 열람 실패.

## 한계 / 정직성 메모
- 'Digitsu Barlaan 기무라', 'Digitsu 백 테이크', 'Bernardo Faria', 'BJJ Ee', 'Mauricio Gomes', 'jiujitsu.com S-mount' 근거는 검색 결과 요약만 확인함(본문 미열람). 해당 항목은 supports에 '검색 요약 기준' 표기, 등급 보수적 책정. 단, '검증됨' sc-kimura-armbar는 본문 열람 2곳(Giles 글, Grapplearts)으로 충족.
- 'sc-backtake-rnc'의 검증됨은 Gordinho(열람) + Digitsu(요약) 조합이라 다음 라운드에서 Digitsu 본문 확인 필요.

## 열린 질문
1. SC-05 '스피닝 암바'는 near-arm step-over인지 far-arm 스피닝인지 정의 확인 필요.
2. 아메리카나 ID가 도감에 없음(기무라 방어 시 가장 흔한 분기).
3. 다르세/아나콘다 쌍 연계의 신뢰 출처 재탐색(Danaher/Gordon Ryan 교본, BJJ Fanatics 설명 등).
4. 암 트라이앵글에서 마운트 전환 연계(소스 미확보), 한국어 출처 확보.
