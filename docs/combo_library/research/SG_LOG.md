# SG 리서치 로그 (2라운드)
- 유효 검색어: "saddle inside sankaku heel hook defended ...", "saddle position kneebar finish ...". 영어, standard 모드.
- page-read 성공: Grapplearts 411 글, Dan Jonaher 무수메시 분석, Living As A Grappler(Diggle 세미나), Digitsu 기술 페이지(saddle-defense, cross-ashi-garami, heel-hook-dilemma, backside-50-50), BJJ More Giles 리뷰.
- 한계: Grapplearts는 영상 중심이라 본문은 챕터 제목 수준. BJJ More/Digitsu는 코스 소개라 동작 세부 부족. bjjee 글은 영상 임베드만 있어 근거로 못 씀.
- 접근 문제: 차단 도메인 없음.
- DB 부족: 백사이드 50/50 진입(포지션) 기술, 새들에서의 히스트/스탠드업 탑 전환, 크로스애시(아웃사이드 애시)에서의 카프 슬라이서(SG-* 없음).
- 룰: 힐훅은 IBJJF 도복 및 하위 벨트에서 불가, 니바도 벨트별 제한. 새들 -> 탑 전환은 힐훅 불가 룰에서도 사용 가능.

## 라운드 3
- 신규 ID 반영: SG-22(대용) -> SG-24로 교체(sg-heelhook-backside5050). SG-14 카프 슬라이서로 sg-heel-calfslicer-kneebar 추가(참고).
- page-read 신규: Digitsu Calf Slicer 페이지. Dan Jonaher 글 재확인(상대가 다리를 벌려 새들 재확립 불가 -> 백사이드 50/50, 앵클락 후 카프 슬라이서 위협).
- 한계: 힐훅 정체 -> 카프 슬라이서를 직접 서술한 페이지 없음(선택지 나열 수준). 카프->니바는 Digitsu 한 곳.
- 재시도: 검색 "saddle calf slicer ..."는 요약만, 본문 기반 승격 불가. 나머지 참고 콤보는 등급 유지.
- 룰: 힐훅 도복 불가, 카프 슬라이서/니바 벨트별 제한.
