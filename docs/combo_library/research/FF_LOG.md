# FF 리서치 로그 (2라운드)
- 유효 검색어: "50/50 guard heel hook defended ... sweep or back step", "50/50 guard straight ankle lock ... transition".
- page-read 성공: Digitsu 50-50 Guard / Heel Hook Dilemma / Jon Calestine 영상 설명 2건, Jitsu IQ 50/50, BJJ More 코스 리뷰(Salles/Maira, Gaudio).
- 한계: '공격 정체 -> 스윕/백 테이크' 연계를 명시한 곳은 Digitsu 한 곳. 나머지는 옵션 나열이라 모두 참고 등급. Ryan Hall 등 개별 강사의 50/50 체인 직접 출처는 못 찾음.
- 접근 문제: 차단 도메인 없음. 일부 결과(10th Planet 포럼, 정체불명 도메인)는 근거로 쓰지 않음.
- DB 부족: 70/30 훅(Tama 락 회피 체인), 에스티마 락, 백사이드 50/50 진입 기술, 50/50 -> 스크램블 탑 전환.
- 룰: IBJJF 도복은 스트레이트 앵클락 위주, 힐훅/토홀드는 제한. 스윕/백 테이크는 룰 무관.
