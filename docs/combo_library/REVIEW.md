# 콤보 라이브러리 검수표 (1차 라운드)

아래 콤보 중 **수련에서 안 쓰거나 어색하게 느껴지는 것**만 번호로 알려 주세요. 제가 등급을 내리거나 삭제합니다.
- 등급 `참고`: 출처가 있으나 본문 확인이 부족해 아직 앱 노출 전 / `초안`: 근거 못 찾음


## 클로즈드 가드

### 1. 크로스 초크 · 암바 연계  `참고`
- 상황: 클로즈드 가드에서 상대 자세를 무너뜨리고 깃 깊이 그립을 잡았을 때
  1. [먼저] 크로스 초크 `CG-10`
  2. [막히면] 암바 `CG-11` (상대가 초크를 피해 몸을 옆으로 틀거나 팔로 내 이두를 밀어 막으면)
- 결과: 암바 서브미션
- 확인할 점: 검색 요약 기반으로 확인, 원문 전체 정독은 미실시. BJJEE는 여러 강사 영상을 소개하는 사이트라 첫 출처(Renzo)와 BJJ Canvas를 독립 2곳으로 계산. 깃(기) 그립 의존 - 노기 부적합.

### 2. 힙범프 · 기무라 · 길로틴 연계  `참고`
- 상황: 클로즈드 가드에서 상대가 상체를 세우고 있을 때
  1. [먼저] 힙범프 스윕 `CG-01`
  2. [막히면] 기무라 `CG-13` (상대가 팔을 빼거나 손을 짚어 버티면)
  3. [막히면] 하이 엘보우 길로틴 `CG-12` (상대가 껴안으며 앞으로 밀고 들어오면)
- 결과: 서브미션 또는 스윕 후 탑 포지션
- 확인할 점: 길로틴 분기는 약하게만 확인됨(상대가 앞으로 밀 때 목 노출). JitsuIQ는 위키성 사이트라 강사 직접 출처 추가 필요. 팔을 짚는 경우는 기무라/트라이앵글로 소개되는 출처가 많음. 힙범프 후 마운트는 MT-20 transition으로 추가 가능하나 이번엔 미포함.

### 3. 암바 · 삼각 · 오모플라타 연계  `참고`
- 상황: 클로즈드 가드에서 상대 팔을 가두고 암바를 시도할 때
  1. [먼저] 암바 `CG-11`
  2. [막히면] 오버훅 트라이앵글 `CG-16` (상대가 팔을 빼며 머리를 숙이고 몸을 돌리면)
  3. [막히면] 오버훅 오모플라타 `CG-17` (상대가 팔을 빼고 자세를 세우며 반대로 빠지면)
- 결과: 삼각 또는 오모플라타 서브미션
- 확인할 점: DB의 CG-16/CG-17은 '오버훅' 변형 이름이라 일반 삼각/오모플라타와 이름이 다름 - 도감에 일반 삼각(클로즈드 가드)이 있으면 교체 검토. 두 분기의 트리거(머리 숙임 vs 자세 세움)는 출처 취지를 요약한 것이라 사람 검수 필요.

### 4. 오버훅 가드 · 삼각 · 오모플라타 연계  `참고`
- 상황: 클로즈드 가드에서 한쪽 팔에 깊은 오버훅을 건 상태
  1. [먼저] 오버훅 클로즈드 가드 `CG-14`
  2. [이어서] 오버훅 트라이앵글 `CG-16`
  3. [막히면] 오버훅 오모플라타 `CG-17` (상대가 삼각을 막으려 팔을 빼거나 자세를 세우면)
- 결과: 삼각 또는 오모플라타 서브미션
- 확인할 점: 오버훅 허브 개념은 일치하나 삼각 -> 오모플라타 순서의 직접 연계 설명은 Grapplearts 1곳. 블로그/위키성 출처가 많아 강사 직접 출처 보강 필요. 기무라(CG-18)는 분기 2개 제한 때문에 별도 콤보 후보.

### 5. 크로스 초크 · 시저 스윕 연계  `참고`
- 상황: 클로즈드 가드에서 크로스 깃 그립과 소매 그립을 잡았을 때
  1. [먼저] 크로스 초크 `CG-10`
  2. [막히면] 시저 스윕 `CG-02` (상대가 초크를 막으려 몸을 세우거나 손으로 짚어 버티면)
- 결과: 탑 포지션(마운트)
- 확인할 점: 두 번째 출처가 초크와의 직접 연계를 확인해 주지 못함. 깃 그립 의존(노기 부적합). 스윕 성공 후 마운트 전환(MT-20)은 확인 안 해 미포함.

### 6. 펜듈럼 스윕 · 암바 연계  `참고`
- 상황: 클로즈드 가드에서 상대가 두 손으로 내 몸통을 짚고 앞으로 기울었을 때
  1. [먼저] 펜듈럼 스윕 `CG-03`
  2. [막히면] 암바 `CG-11` (상대가 자유로운 손을 짚어 버티면)
- 결과: 서브미션 또는 마운트
- 확인할 점: 출처 1곳, 암바 세부 동작은 해당 글에 없음. 강사 직접 출처 필요. 플라워 스윕(CG-04)과 펜듈럼은 같은 기술로 취급되는 출처 있음 - 도감 중복 여부 확인.

### 7. 오버훅 · 암드래그 백테이크  `초안`
- 상황: 클로즈드 가드에서 한쪽 팔을 오버훅으로 컨트롤한 상태
  1. [먼저] 오버훅 클로즈드 가드 `CG-14`
  2. [이어서] 클로즈드가드 백테이크 `CG-21`
- 결과: 백 포지션
- 확인할 점: 클로즈드 가드 암드래그 백테이크는 소수 출처가 개념만 언급(Evolve 암드래그 목록), 구체 연계 근거 부족. 유명 암드래그 사례(Marcelo Garcia)는 대부분 버터플라이/스탠딩 기반이라 CG에 적용하려면 별도 확인 필요. 백 포지션 전환 ID는 해당 포지션 DB에서 확인 후 transition으로 추가.


## 사이드 컨트롤

### 8. 기무라 · 암바 연계 (팔을 펴고 버틸 때)  `참고`
- 상황: 사이드 컨트롤 탑에서 상대의 팔을 기무라 그립으로 잡았을 때
  1. [먼저] 기무라 (사이드 컨트롤) `SC-01`
  2. [막히면] 암바 (사이드 컨트롤) `SC-02` (상대가 팔을 펴서 버티며 굴러 도망가지 않으면)
- 결과: 암바 서브미션
- 확인할 점: 상대가 팔을 당겨 빼면 아메리카나로 가는 갈래가 소스에 나오지만 도감에 아메리카나 ID가 없어 넣지 못함. 트리거 문구('굴러 도망가지 않으면')는 Giles 설명을 바탕으로 한 정리. 노기/노기 모두 가능(그립 비의존).

### 9. 기무라 그립 · 백 테이크  `참고`
- 상황: 사이드 컨트롤 탑에서 가까운 쪽 팔 기무라 그립을 잡은 상태
  1. [먼저] 기무라 (사이드 컨트롤) `SC-01`
  2. [이동] 백 테이크 (사이드에서) `SC-11`
- 결과: 백 포지션 (이후 BC-01 등으로 연계 가능)
- 확인할 점: 두 번째 출처는 검색 요약으로만 확인(원문 미열람)이라 독립 2출처로 인정하지 않음. 상세 백 테이크 동작은 Giles 영상 확인 필요. 이 콤보의 백 테이크가 SC-11과 정확히 같은 동작인지 불확실.

### 10. 프레임 방어를 이용한 스피닝 암바  `참고`
- 상황: 사이드 컨트롤 탑에서 상대가 팔로 엉덩이/목을 밀며 프레임을 만들 때
  1. [먼저] 사이드 컨트롤 기본 컨트롤 `SC-20`
  2. [이어서] 스피닝 암바 `SC-05`
- 결과: 암바 서브미션
- 확인할 점: 두 출처 모두 검색 결과 요약으로만 확인했고 페이지 본문을 직접 열람하지 못해 '검증됨'으로 올리지 않음. 도감의 '스피닝 암바(SC-05)'가 소스의 near-arm step-over armbar와 같은 기술인지 확인 필요(far-arm 스피닝 암바와 구분).

### 11. 먼 쪽 언더훅 마르셀로 암바  `참고`
- 상황: 사이드 컨트롤 탑에서 상대의 먼 쪽 팔에 언더훅을 얻었을 때
  1. [먼저] 사이드 컨트롤 기본 컨트롤 `SC-20`
  2. [이어서] 암바 (사이드 컨트롤) `SC-02`
- 결과: 암바 서브미션
- 확인할 점: 출처 1곳. 이름 '마르셀로 암바'는 Kesting의 표현이며 도감 SC-02와 동일 기술의 변형으로 취급.

### 12. 사이드 컨트롤 암 트라이앵글  `참고`
- 상황: 사이드 컨트롤 탑에서 상대 팔이 얼굴/목 쪽으로 올라와 있을 때
  1. [먼저] 사이드 컨트롤 기본 컨트롤 `SC-20`
  2. [이어서] 암 트라이앵글 (사이드 컨트롤) `SC-04`
- 결과: 초크 서브미션
- 확인할 점: 두 출처 모두 일반 설명이며 상대 반응별 연계(트리거)를 제시하지 않아 '검증됨' 보류. 블랙벨트 강사 직접 출처 추가 필요(예: Lucas Lepri Digitsu는 시트벨트 기반이라 사이드 컨트롤과 직접 대응 안 됨).

### 13. 다르세 · 아나콘다 연계  `초안`
- 상황: 사이드 컨트롤 탑에서 상대가 안쪽으로 돌아 들어오며 언더훅/탈출을 시도할 때
  1. [먼저] 다르세 초크 `SC-03`
  2. [막히면] 아나콘다 초크 `SC-06` (상대가 팔을 빼거나 고개를 반대로 돌려 다르세가 막히면)
- 결과: 초크 서브미션
- 확인할 점: 다르세와 아나콘다는 거울상 관계라는 설명은 있으나, 사이드 컨트롤에서 다르세->아나콘다로 바꾸는 연계를 직접 다룬 신뢰 출처를 찾지 못함. 아나콘다는 주로 프런트 헤드락에서 설명됨. 앱 노출 금지, 다음 라운드 재조사.

### 14. 사이드 컨트롤 백 테이크 · 리어 네이키드 초크  `참고`
- 상황: 사이드 컨트롤 탑에서 상대가 등을 돌려 탈출하려 할 때
  1. [이동] 백 테이크 (사이드에서) `SC-11`
  2. [이어서] 리어 네이키드 초크 (RNC) `BC-01`
- 결과: RNC 서브미션
- 확인할 점: 타 포지션(BC-01)이 포함된 교차 포지션 콤보: SC-11은 전환이므로 마지막 전환 규칙의 예외 형태(전환 후 후속 기술). 두 출처의 백 테이크 디테일(상대가 도는 방향)이 서로 다름. Digitsu는 요약만 확인.

### 15. 사이드 컨트롤 · 마운트 · S-마운트 암바  `참고`
- 상황: 사이드 컨트롤 탑에서 상대 엉덩이를 돌려 마운트 진입이 가능할 때
  1. [이동] 마운트 전환 (사이드에서) `SC-10`
  2. [이어서] S-마운트 암바 `MT-05`
- 결과: 암바 서브미션
- 확인할 점: 두 출처가 각각 전환과 암바를 따로 다루며 하나의 연계로 소개한 곳은 못 찾음. 도감 사이드 컨트롤 ID로 시작하나 후속 MT-05는 교차 포지션. 두 출처 모두 요약 기준이라 원문 확인 필요. 칼라 그립 기반(기)이므로 노기에서는 변형 필요.


## 마운트

### 16. 하이 마운트 · S-마운트 · 암바 연계  `참고`
- 상황: 마운트 탑에서 상대가 팔꿈치와 손으로 밀어내며 빠지려 할 때
  1. [먼저] 하이 마운트 `MT-21`
  2. [이어서] S-마운트 암바 `MT-05` (상대가 팔로 밀어 막거나 팔을 가슴 앞에 세우면)
  3. [이어서] 마운트 암바 `MT-01`
- 결과: 암바 서브미션
- 확인할 점: 검색 요약 기반으로 근거를 확인함(페이지 본문 전체 미열람). 하이 마운트->S-마운트 전환을 한 문서가 순서대로 다루지는 않고 출처별로 일부씩 뒷받침. 기 사용 시 칼라 그립 변형 있음.

### 17. 크로스 초크 미끼 · 암바 연계  `참고`
- 상황: 기(도복) 마운트 탑에서 상대가 아직 팔을 몸에 붙이고 방어할 때
  1. [먼저] 크로스 초크 (마운트) `MT-02`
  2. [막히면] 마운트 암바 `MT-01` (상대가 손으로 초크를 막거나 팔을 뻗어 밀어내거나 업빠로 뒤집으려 팔을 잡으면)
- 결과: 암바 서브미션
- 확인할 점: 두 번째 출처는 연계를 직접 설명하지 않아 1곳 근거로 판단. 검색 요약에 나온 '초크 위협이 팔을 노출시킨다'는 설명은 출처 URL을 정확히 특정하지 못해 인용하지 않음. 기(도복) 전용 기술.

### 18. 기프트랩 · 백 테이크 · RNC 연계  `참고`
- 상황: 마운트 탑에서 상대가 옆으로 몸을 돌리며 압박을 피하려 할 때
  1. [먼저] 기프트랩 → 백테이크 `MT-11`
  2. [이어서] 리어 네이키드 초크 (RNC) `BC-01`
- 결과: RNC 서브미션 (백 컨트롤)
- 확인할 점: BC-01은 다른 포지션(백 컨트롤) 기술이므로 크로스 포지션 콤보. MT-11이 이미 백테이크를 포함한 전환 기술이라 MT-11 안에 훅 넣는 동작이 들어 있음. RNC 마무리는 RNC 일반 설명(백에서 RNC)에 근거. 기프트랩 자체는 사이드 컨트롤에서도 쓰임.

### 19. 마운트 기무라 · 암바 전환 연계  `참고`
- 상황: 마운트 탑에서 상대가 두 팔을 가슴 앞이나 매트에 붙이고 버틸 때
  1. [먼저] 기무라 (마운트) `MT-03`
  2. [막히면] 마운트 암바 `MT-01` (상대가 그립을 끊고 팔을 펴거나 밀어내면)
- 결과: 암바 또는 기무라 서브미션
- 확인할 점: 출처 1곳이며 마운트 특정 서술이 아니라 일반 기무라 설명. 마운트에서의 기무라->암바 순서는 추가 근거 필요. 도감에 아메리카나가 없어 MT-03(기무라)로만 표기.

### 20. 기무라 · 암 트라이앵글 짝 연계  `초안`
- 상황: 마운트 탑에서 상대가 한 팔을 머리 옆으로 올려 막을 때
  1. [먼저] 기무라 (마운트) `MT-03`
  2. [막히면] 암 트라이앵글 (마운트) `MT-04` (상대가 기무라를 막으려 팔을 목 쪽으로 가져오면)
- 결과: 암 트라이앵글 또는 기무라 서브미션
- 확인할 점: 검색(영/한)에서 마운트 기무라와 암 트라이앵글을 짝으로 다룬 신뢰 가능한 출처를 찾지 못함(포럼 일화 수준만 확인). 다음 라운드에서 마운트 시스템 교본/Grapplearts 직접 탐색 필요.

### 21. 암바 방어 시 백 테이크 연계  `초안`
- 상황: 마운트 암바를 시도했는데 상대가 팔꿈치를 굽혀 팔을 빼려 할 때
  1. [먼저] 마운트 암바 `MT-01`
  2. [막히면] 백 테이크 (마운트에서) `MT-10` (상대가 팔을 빼며 옆으로 돌아 등을 보이면)
- 결과: 백 컨트롤 (포지션 전환)
- 확인할 점: '마운트에서 팔 바깥으로 나가면 암 트라이앵글이나 백 테이크'라는 일반 조언만 포럼 수준에서 확인. 암바 방어 후 백 테이크를 직접 다룬 강사 자료는 찾지 못함. MT-10은 백 포지션 전환이라 마지막 단계로 배치.

### 22. 브릿지 대응 기술적 마운트 전환 연계  `초안`
- 상황: 마운트 기본 컨트롤에서 상대가 강하게 브릿지하며 돌아누우려 할 때
  1. [먼저] 마운트 기본 컨트롤 `MT-20`
  2. [막히면] S-마운트 암바 `MT-05` (상대가 브릿지를 반복하며 몸이 옆으로 돌면)
- 결과: 탑 유지 후 암바 시도
- 확인할 점: 근거는 검색 요약 수준 1곳이며 연계 방향(기술적 마운트 = MT-05?)이 불확실해 등급을 초안으로 유지. 도감에 '기술적 마운트' ID가 없어 MT-05(S-마운트)로 대체했으나 일부 출처는 두 자세를 다른 것으로 구분함.


## 백 컨트롤

### 23. 백 컨트롤 · RNC · 손 방어 시 암바 연계  `참고`
- 상황: 훅과 시트벨트 그립으로 백 컨트롤을 잡았을 때
  1. [먼저] 백 컨트롤 기본 `BC-20`
  2. [이어서] 리어 네이키드 초크 (RNC) `BC-01`
  3. [막히면] 암바 (백 컨트롤) `BC-03` (상대가 양손을 목으로 올려 초크를 막아 팔꿈치가 벌어지면)
- 결과: 서브미션(RNC 또는 암바)
- 확인할 점: 두 출처 모두 웹 검색 요약으로만 확인했고 페이지 본문 전체는 열람하지 못함. 노기/기 모두 가능(그립 비의존). 암바 전환 디테일은 출처마다 다를 수 있음.

### 24. RNC 방어 시 숏 초크 전환  `참고`
- 상황: 백 컨트롤에서 RNC를 시도했는데 상대가 손과 턱으로 막을 때
  1. [먼저] 백 컨트롤 기본 `BC-20`
  2. [이어서] 리어 네이키드 초크 (RNC) `BC-01`
  3. [막히면] 숏 초크 `BC-06` (상대가 양손으로 초크 팔을 막아 RNC가 들어가지 않으면)
- 결과: 서브미션(숏 초크)
- 확인할 점: 두 출처가 교육 블로그/영상 플랫폼 요약 수준이며 강사 본인 채널 직접 자료는 못 찾음. 마르셀로 가르시아의 구체적 전환 영상은 확인하지 못함. 숏 초크는 노기 가능. 마무리 시 언더훅을 풀어 탈출 틈이 생길 수 있다는 주의 있음.

### 25. 바디 트라이앵글 · RNC · 암바 연계  `참고`
- 상황: 바디 트라이앵글로 백을 단단히 묶고 상대 팔 하나를 잡았을 때
  1. [먼저] 바디 트라이앵글 컨트롤 `BC-21`
  2. [이어서] 리어 네이키드 초크 (RNC) `BC-01`
  3. [막히면] 암바 (백 컨트롤) `BC-03` (상대가 손으로 초크 팔을 잡고 턱을 숙여 막으면)
- 결과: 서브미션(RNC 또는 암바)
- 확인할 점: 강사 본인 자료가 아닌 목록형/포럼 근거라 약함. 바디 트라이앵글은 다리 길이/체급에 따라 걸기 어렵고 암바 전환 시 풀려야 하는 한계가 있음(출처 미확인, 확인 필요). 노기/기 모두 가능.

### 26. 스트레이트 자켓 컨트롤 · 보우 앤 애로우 연계  `참고`
- 상황: 도복 상태에서 백 컨트롤을 잡고 상대 양팔을 묶어 목 방어를 막았을 때
  1. [먼저] 스트레이트 자켓 컨트롤 `BC-22`
  2. [이어서] 보우 앤 애로우 초크 `BC-02`
  3. [막히면] 암바 (백 컨트롤) `BC-03` (상대가 초크에서 머리를 빼내면)
- 결과: 서브미션(보우 앤 애로우 또는 암바)
- 확인할 점: 스트레이트 자켓 → 보우 앤 애로우는 JitsuIQ 1곳만 직접 설명. 보우 앤 애로우 → 손목락 연계는 별개 영상이며 손목락은 도감에 없어 암바(BC-03)로 대체했음. 도복 필수(보우 앤 애로우는 노기 불가). 스트레이트 자켓과 보우 앤 애로우 연결이 실제 강사 자료에서도 같은 흐름인지 추가 확인 필요.

### 27. 백 기무라 컨트롤 · 암바 연계  `참고`
- 상황: 백 컨트롤에서 상대가 목을 철저히 보호하며 팔을 모으고 있을 때
  1. [먼저] 기무라 (백 컨트롤) `BC-04`
  2. [막히면] 암바 (백 컨트롤) `BC-03` (기무라가 들어가지 않고 팔이 풀리거나 팔이 펴질 때)
- 결과: 서브미션(기무라 또는 암바)
- 확인할 점: Grapplearts는 기무라 → 트라이앵글(도감에 BC 코드 없음)을 설명하고, 암바 방향은 Evolve 요약에만 나와 방향이 조금 다름. 로저 그레이시(Graciemag) 영상은 기무라가 막히면 무릎을 등 뒤로 옮겨 깃 초크로 가는 연계를 보여주므로 BC-04 → 칼라 초크 변형도 후보지만 도감에 해당 기술이 없어 미반영. 노기 가능.

### 28. RNC 방어 시 깃 보우 앤 애로우 전환 (도복)  `초안`
- 상황: 도복 상태 백 컨트롤에서 RNC를 상대가 손으로 막을 때
  1. [먼저] 백 컨트롤 기본 `BC-20`

  3. [막히면] 보우 앤 애로우 초크 `BC-02` (상대가 맨손 목 방어를 단단히 하면)
- 결과: 서브미션(보우 앤 애로우)
- 확인할 점: RNC가 막혔을 때 보우 앤 애로우로 가는 직접 연계를 설명하는 출처는 못 찾음. 보우 앤 애로우 자체 방법만 확인. 도복 필수.

### 29. 백 시스템 초크 콤보 · 숏 초크  `초안`
