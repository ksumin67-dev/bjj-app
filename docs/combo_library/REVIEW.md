- 결과: 서브미션(숏 초크)
- 확인할 점: [본문 확인 완료 2026-10-10] Evolve MMA와 Digitsu 본문 확인(별도 확인한 Evolve University 4옵션 글도 같은 취지이나 Evolve 계열이라 1곳으로 계산). 두 곳 모두 교육 블로그/기술 데이터베이스 수준이며 강사 본인 채널 직접 자료는 못 찾음. 마르셀로 가르시아의 구체적 전환 영상은 확인하지 못함. 숏 초크는 노기 가능. 마무리 시 언더훅을 풀어 탈출 틈이 생길 수 있다는 주의 있음.

  3. [막히면] 암바 (백 컨트롤) `BC-03` (상대가 손으로 초크 팔을 잡고 턱을 숙여 막으면)
- 결과: 서브미션(RNC 또는 암바)
- 확인할 점: [본문 확인 2026-10-10] Digitsu는 목록 수준(트리거 없음), Bullshido는 포럼 의견이라 근거로 약함. 강사 본인 자료 필요. 바디 트라이앵글은 다리 길이/체급에 따라 걸기 어렵고 암바 전환 시 풀려야 하는 한계가 있음(출처 미확인, 포럼 글에서 암바 실패 시 포지션을 잃는다는 경험담은 있음). 노기/기 모두 가능.

### 4. 스트레이트 자켓 컨트롤 · 보우 앤 애로우 연계  `참고`
- 상황: 도복 상태에서 백 컨트롤을 잡고 상대 양팔을 묶어 목 방어를 막았을 때

  3. [막히면] 암바 (백 컨트롤) `BC-03` (상대가 초크에서 머리를 빼내면)
- 결과: 서브미션(보우 앤 애로우 또는 암바)
- 확인할 점: [본문 확인 2026-10-10] 두 페이지 본문 확인. 스트레이트 자켓 -> 보우 앤 애로우 연계는 JitsuIQ(위키성) 1곳, 보우 앤 애로우 -> 손목락/암바 연계는 Digitsu 1곳으로 각 고리가 한 출처씩만 뒷받침. 손목락은 도감에 없어 암바(BC-03)로 대체(Digitsu는 손목락을 주 선택지, 암바는 기회가 될 때로 서술). 도복 필수(보우 앤 애로우는 노기 불가).

### 5. 백 기무라 컨트롤 · 암바 연계  `검증됨`
- 상황: 백 컨트롤에서 상대가 목을 철저히 보호하며 팔을 모으고 있을 때
  1. [먼저] 기무라 (백 컨트롤) `BC-04`
  2. [이어서] 암바 (백 컨트롤) `BC-03`
- 결과: 서브미션(기무라 또는 암바)
- 확인할 점: 노기 가능. [본문 확인 완료 2026-10-10] Evolve University와 Grapplearts(글 + Kimura Cheatsheet PDF) 본문 확인. 두 출처 모두 기무라 컨트롤 -> 암바를 "선택지"로 서술할 뿐 "기무라가 풀리거나 팔이 펴질 때"라는 트리거는 근거가 없어 BC-03을 if_blocked에서 then으로 바꾸고 트리거를 삭제함. Grapplearts는 기무라 -> 삼각(도감에 BC 코드 없음)을 중심으로 서술하고 암바는 삼각 경유 또는 일반 서술. Graciemag 로저 그레이시 영상(기무라가 막히면 칼라 초크)은 이번에 읽지 않음, 미반영. [3라운드] BC-11(백 트라이앵글)이 도감에 추가되어 기무라 -> 삼각 연계는 bc-kimura-triangle 콤보로 분리.

### 6. RNC 방어 시 깃 보우 앤 애로우 전환 (도복)  `참고`
- 상황: 도복 상태 백 컨트롤에서 RNC를 상대가 손으로 막을 때
  1. [먼저] 백 컨트롤 기본 `BC-20`
  2. [이어서] 리어 네이키드 초크 (RNC) `BC-01`
  3. [막히면] 보우 앤 애로우 초크 `BC-02` (상대가 손으로 목을 단단히 보호해 RNC를 잠글 수 없으면)
- 결과: 서브미션(보우 앤 애로우)
- 확인할 점: [3라운드 재시도] Digitsu Barlaan 설명 본문 확인으로 "RNC보다 보우 앤 애로우가 낫다"는 방향의 근거 1곳 확보 -> 참고로 승격. 단 RNC를 먼저 시도하고 막히면 전환한다는 순서까지는 서술하지 않음. BJJEE 글은 여전히 검색 요약(snippet). 독립 page-read 1곳. 도복 필수.

### 7. 백 시스템 초크 콤보 · 숏 초크  `초안`
- 상황: 백 컨트롤에서 한 가지 초크가 막혔을 때 계속 그립을 바꿔 압박할 때
  1. [먼저] 백 시스템 초크 콤보 `BC-05`
  2. [막히면] 숏 초크 `BC-06` (초크 팔이 턱 아래로 들어가지 않으면)
- 결과: 서브미션
- 확인할 점: BC-05(백 시스템 초크 콤보)의 구체적 내용이 정의된 출처를 찾지 못함. 도감 기술 설명을 먼저 확인한 뒤 재시도. 내용 불명확해 앱 노출 금지. [3라운드] 재시도하지 못함(BC-05의 구체적 내용이 정의된 출처가 없어 초안 유지).

### 8. 백 암바 실패 시 마운트 전환  `초안`
- 상황: 백에서 암바를 시도했는데 상대가 팔을 빼거나 깍지로 버틸 때
  1. [먼저] 암바 (백 컨트롤) `BC-03`
  2. [이동] 마운트 전환 (백에서) `BC-10`
- 결과: 마운트
- 확인할 점: 백 암바 실패 후 마운트로 가는 연계 출처 못 찾음. BC-10은 마지막 단계로만 배치함. [3라운드 재시도] "armbar from back fails transition to mount" 재검색: 백을 잃은 뒤 마운트로 가는 글(BJJEE)만 나오고 백 암바 실패 -> 마운트 연계 근거 없음. 초안 유지.

- 확인할 점: [3라운드 신규] BC-11 사용. Evolve University와 Grapplearts는 이전 라운드에서 본문 확인한 근거를 재사용(기존 bc-kimura-control-armbar와 동일 출처), Digitsu는 이번에 새로 본문 확인. 노기 가능.

### 10. RNC 방어 시 백 트라이앵글 전환  `참고`

### 11. 백 트라이앵글 · 암락 마무리  `검증됨`

  2. [이어서] 암바 (백 컨트롤) `BC-03`
- 결과: 암바 서브미션
- 확인할 점: [3라운드 신규] 세 곳 모두 "삼각 완성 후 선택지로 암락"을 서술하며 반응 트리거(어떨 때 암바로 가는지)는 명시하지 않아 role을 then으로 둠. Evolve는 암락 중 기무라/스트레이트/손목락을 나열하며 암바(BC-03)와 정확히 같은 동작인지 사람 검수 필요.


## 버터플라이 가드

### 12. 버터플라이 스윕 · 삼각 셋업 연계 (손을 짚을 때)  `검증됨`
- 상황: 버터플라이 가드에서 상대를 앞으로 끌어당겨 스윕을 걸었을 때
  1. [먼저] 기본 버터플라이 스윕 `BF-01`
  2. [막히면] 버터플라이 트라이앵글 셋업 `BF-11` (상대가 손을 바닥에 짚어 스윕을 막으면)
- 결과: 삼각 초크 셋업(서브미션 시도) 또는 스윕 성공 시 탑 포지션
- 확인할 점: 도감 BF-11은 '삼각 셋업'이므로 초크 완성 단계(일반 삼각 초크)는 DB에 없음(삼각 초크 일반 ID 없음, 보강 후보). 세 번째 출처(GB)는 영상 제목 수준의 짧은 설명이라 방향 근거가 약함. 기/노기 모두 가능하나 노기에서는 손목·삼두 그립 위주.

### 13. 버터플라이 스윕 · 길로틴 트랩 연계 (상대가 팔로 버티고 엉덩이를 낮출 때)  `참고`
- 상황: 버터플라이 가드에서 컬러 타이와 삼두 컨트롤로 기본 스윕을 시도할 때
  1. [먼저] 기본 버터플라이 스윕 `BF-01`
  2. [막히면] 버터플라이 길로틴 트랩 `BF-10` (상대가 팔로 바닥을 짚고 엉덩이를 내려 스윕을 막으면)
- 결과: 길로틴 초크 서브미션 또는 스윕 성공 시 하프 가드 탑
- 확인할 점: 독립된 page-read 출처가 1곳뿐. 마르셀로의 영상 설명을 요약한 제3자 글이라 강사 본인 페이지를 추가로 확인해야 함. 길로틴 그립이 노기 기준이며 기에서는 칼라 그립이 다른 방어에 막힐 수 있음. 도감 BF-10은 '길로틴 트랩'이라 정확한 피니시 동작은 별도 확인 필요.

### 14. 버터플라이 스윕 · 숄더 크런치 수미가에시 (손을 짚을 때)  `검증됨`
- 상황: 버터플라이 가드에서 상대를 앞으로 끌어 스윕 위협을 줄 때
  1. [먼저] 암드래그 (버터플라이) `BF-25`
  2. [막히면] 숄더 크런치 수미가에시 `BF-02` (상대가 넘어지지 않으려 손을 바닥에 짚어 팔이 머리 위로 뻗어지면)
- 결과: 마운트 또는 탑 패싱 포지션
- 확인할 점: 3라운드: 앞 단계를 BF-01(스윕 위협)에서 BF-25(암드래그)로 교체. Gordon Ryan 사례는 암드래그와 후크로 끌어당긴 뒤 상대가 손을 짚을 때 숄더 크런치를 걸었다는 설명이라 BF-25와 더 잘 맞음. 노기 위주 기술이며 기에서는 소매·칼라 그립으로 변형. 난이도가 높아 level 고급.

### 15. 버터플라이 스윕 · X가드 전환 · 스탠드업 스윕  `참고`
- 상황: 버터플라이 가드에서 한 손은 칼라, 다른 손은 무릎 바지를 잡고 스윕을 시도할 때
  1. [먼저] 기본 버터플라이 스윕 `BF-01`
  2. [막히면] 버터플라이 → X가드 전환 `BF-20` (상대가 발을 뒤로 딛거나 밀어내며 스윕을 막을 때)
  3. [이어서] 스탠드업 스윕 `XG-01`

- 확인할 점: 근거가 Marcus Johnson 코스 1곳 page-read뿐이라 검증됨 불가. 두 번째 출처는 폴딩 패스 연계를 다루지 않음. 접은 뒤 마무리 단계(GP-20)는 같은 코스 설명 기준.

### 46. 스택 패스 · 막히면 반대쪽 전환 후 롱스텝  `참고`
- 상황: 클로즈드 가드를 열고 스택 패스로 무릎을 눌러 올릴 때
  1. [먼저] 스택 패스 `GP-23`
  2. [막히면] 롱 스텝 패스 `GP-19` (상대가 힙과 얼굴에 프레임해 무릎이 팔 위로 넘어가지 않으면)

### 47. 레그 위브 패스 · 상대가 프레임하면 백스텝 패스  `검증됨`
- 상황: 오픈가드 상대의 다리 사이로 팔을 넣어 무릎 라인을 눌러 고정할 때
  1. [먼저] 레그 위브 패스 `GP-03`
  2. [막히면] 백스텝 패스 `GP-02` (상대가 머리나 이두에 프레임을 만들고 힙을 빼 리가드하려 하면)
  3. [이어서] 패스 → 사이드 컨트롤 전환 `GP-20`

### 48. 백스텝 패스 · 상대가 등을 돌리면 백 테이크  `검증됨`
- 상황: 한쪽 다리를 잡고 상체를 컨트롤한 채 백스텝 패스를 시작할 때

- 확인할 점: Jitsu IQ와 Digitsu가 서로 독립된 출처로 같은 분기(돌면 백 테이크)를 설명. Bodylock Pass는 보조 근거(다른 패스). GP-22는 마지막 단계의 전환. 상대가 안쪽으로 파고들 때 니 컷 전환은 이 콤보에 넣지 않음. 도복/노기 모두 가능.

### 60. 상대가 앞으로 눌러올 때 · SLX 진입  `참고`
- 상황: K가드에서 상대를 움직여 균형을 파악하고 상대가 앞으로 압박해 올 때

- 확인할 점: SLX 진입은 Benayoun 1곳. Calestine 페이지는 X가드라 방향이 다름. 도감 KG-22 'SLX 전환'이 소스 기술과 일치하는지 확인 필요. 이후 SLX에서의 스윕/레그락은 별도 포지션(SLX) 콤보로. 노기 중심.

### 61. K훅 · 기본 K가드 스윕 (다리 스쿠프 후 밀어 올리기)  `참고`
- 상황: K가드에서 상대의 먼 다리를 스쿠프할 수 있을 때
  1. [먼저] K가드 기본 컨트롤 `KG-20`
  2. [이어서] 기본 K가드 스윕 `KG-01`
  3. [막히면] K가드 시저 스윕 `KG-03` (상대가 먼 다리를 빼고 거리를 유지해 스쿠프가 안 되면)

- 확인할 점: 출처의 동작은 '스윕/히스트(일어서서 탑)'이며 DB의 SG-02(새들 롤 오버 스윕)와 같은 동작인지 확인되지 않아 등급을 참고로 유지. 두 출처 모두 연계 방향(힐 실패 -> 탑)은 일치. 힐훅 불가 룰에서도 쓸 수 있는 연계.

### 110. 새들 니바 · 힐훅 딜레마  `참고`

### 111. 새들 보조 다리 없이 상대가 돌 때 백 테이크  `참고`

### 112. 새들 인사이드 힐훅 · 아웃사이드 힐훅 전환  `참고`

### 113. 새들 힐 공격 정체 시 카프 슬라이서 · 다리를 펴면 니바  `참고`

## 싱글 레그 X가드

### 114. 싱글 레그 X 힙범프(싯업) 스윕 · 앵클락  `참고`
- 상황: 싱글 레그 X가드를 만들고 상대 발목을 겨드랑이/가슴에 끼운 상태

  2. [이어서] 스트레이트 앵클락 `SLX-10`

### 115. 싱글 레그 X 토홀드 · 니바 (상대가 굴러 빠질 때)  `참고`
- 상황: 싱글 레그 X가드에서 상대 칼라를 당겨 자세를 무너뜨린 상태

  2. [막히면] 싱글 레그 X 니바 `SLX-14` (상대가 토홀드를 피해 굴러 빠져나가려 할 때)

- 확인할 점: 연계 방향을 직접 다룬 page-read 출처가 1곳(재게재 기사)이라 검증됨 보류. 룰: 토홀드·니바는 IBJJF에서 하위 벨트(화이트~퍼플)와 일부 기 부문에서 제한됨(출처마다 설명 차이, 대회 규정 확인 필수). 노기에서 일반적.

### 116. 싱글 레그 X · 아웃사이드 아시 · 힐훅 (노기 레그락)  `참고`
- 상황: 싱글 레그 X가드에서 상대 다리를 고립해 레그락 포지션을 잡으려 할 때
  1. [먼저] 아웃사이드 아시 전환 `SLX-21`
  2. [이어서] 아웃사이드 힐훅 `SLX-11`
- 결과: 힐훅 서브미션
- 확인할 점: 두 출처 모두 선택지를 나열할 뿐 'SLX → 아웃사이드 아시 → 힐훅' 순서의 구체 설명이 아님 → 조합은 추정이라 참고 등급. 룰: 힐훅은 IBJJF 기(도복) 대회에서 전반적으로 금지, 노기 상위 부문에서만 허용(출처 간 차이 있음, 대회별 확인 필수). 부상 위험이 가장 높은 기술 — 앱 노출 시 주의 문구 필요. 이번 라운드에서 아웃사이드 아시 전환 전용 강사 자료는 페이월로 열람 못 함.

### 117. 웨이터 스윕이 안 될 때 · 백 테이크  `참고`
- 상황: 싱글 레그 X에서 상대 다리를 어깨에 올려 웨이터(펜들럼) 스윕을 시도할 때
  1. [먼저] SLX 웨이터 스윕 `SLX-05`
  2. [막히면] 크랩 라이드 백테이크 `SLX-24` (상대가 베이스가 강해 스윕이 안 넘어가면)
- 결과: 탑 포지션 또는 백 컨트롤
- 확인할 점: 라운드3: 기존 초안(SLX-01 → 크랩 라이드)은 트리거 근거가 없어 폐기하고 Grippo 페이지의 실제 흐름(웨이터 스윕 불발 → 백 테이크)으로 재작성. Grippo는 SLX에서 직접 설명, Benayoun은 숏 훅 X가드 맥락이라 방향이 조금 다름 → 참고. 도감 SLX-24 '크랩 라이드 백테이크'와 두 강사가 쓰는 '뒷문으로 나가 시트벨트' 흐름이 같은 기술인지는 이름 불일치(크랩 라이드 용어 미사용)로 검수 필요. 기/노기 공통(Benayoun은 기에서 라펠 그립, 노기에서는 힙/다리/어깨 그립).

### 118. 싱글 레그 X ↔ X가드 전환  `검증됨`
- 상황: 싱글 레그 X에서 상대 체중이 한쪽 다리에 실려 있을 때

### 123. 트라이포드 · 시클 스윕 · X가드 전환 (스윕이 막힐 때)  `참고`

  3. [막히면] 스파이더 X가드 전환 `SP-22` (시클도 막혀 상대가 손으로 바닥을 짚을 때)
